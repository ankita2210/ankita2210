### 1. Enterprise Application & Database — AWS Migration

**Domain:** Cloud Modernization | Backend Engineering

**Situation:** A business-critical application and its relational database were running on legacy on-premises infrastructure, creating operational dependencies and limiting further cloud modernization.

**Task:** Lead the migration of the application and database to AWS while maintaining compatibility with existing integrations and batch workloads.

**Action:**
- Planned and coordinated a lift-and-shift migration of the application, SQL Server database, batch jobs, and downstream integrations.
- Established secure hybrid connectivity and AWS-based load balancing and traffic routing.
- Redesigned database-dependent integrations to use HTTP APIs, reducing direct database coupling.
- Coordinated dependency upgrades, testing, deployment readiness, rollback planning, and stakeholder sign-offs.

**Result:** Migrated a critical application to AWS, reduced dependencies on legacy infrastructure, and established a foundation for subsequent cloud modernization.

**Technologies:** AWS, SQL Server, REST APIs, Load Balancing, Hybrid Connectivity, System Integration

### 2. Distribution Automation Platform

**Domain:** Backend Engineering | Distributed Systems | Workflow Automation

**Situation:** A multi-step operational process relied on manual coordination, fragmented data, and limited visibility into approvals and processing status.

**Task:** Build an end-to-end platform to consolidate data, calculate allocations, manage approvals, and track downstream processing.

**Action:**
- Designed and implemented REST APIs and backend workflows using Kotlin.
- Developed asynchronous workers and concurrent processing for independent operations.
- Introduced event-driven synchronization using Amazon SQS to reduce tightly coupled service interactions.
- Implemented approval state management, validation, concurrency controls, idempotent retries, and failure handling.
- Built a React interface to support operational workflows and status tracking.

**Result:** Replaced a fragmented manual process with a centralized, automated workflow designed for reliable processing and future extensibility.

**Technologies:** Kotlin, React, REST APIs, AWS SQS, SQL, Event-Driven Architecture, Asynchronous Processing

---

### 3. Request & Allocation Management Platform

**Domain:** Backend Engineering | Data Integrity | Workflow Design

**Situation:** Requests, approvals, financial allocations, and reporting were managed across disconnected processes, making historical changes and available balances difficult to track.

**Task:** Develop a centralized module for request creation, approval, historical tracking, and monthly and year-to-date reporting.

**Action:**
- Designed a version-controlled data model to preserve previously approved records when changes were submitted for approval.
- Implemented configurable categories and end-to-end request approval workflows.
- Developed dashboards for monthly and year-to-date summaries and available balances.
- Added period-locking functionality to protect finalized records.
- Designed the solution to accommodate additional request categories and rules.

**Result:** Established a single source of truth for request management and reporting, improving traceability, historical accuracy, and data integrity.

**Technologies:** Java, React, SQL, REST APIs, Data Modeling, Versioning, Workflow Automation

---

### 4. Threshold-Based Ownership & Allocation Platform

**Domain:** Backend Engineering | Business Rules | Financial Data Processing

**Situation:** Allocation ownership changed when predefined funding thresholds were reached, but tracking ownership percentages, valuations, and historical changes required manual calculations.

**Task:** Extend an existing platform to calculate ownership splits automatically and provide life-to-date financial reporting.

**Action:**
- Implemented configurable threshold rules at the category level.
- Added validation for threshold changes during an active reporting period.
- Integrated financial reference data, including valuation, fee, and interest information.
- Implemented calculations for ownership percentages, valuations, and gains or losses.
- Built detailed and summary dashboards, with annual locking to preserve finalized records.

**Result:** Automated ownership calculations and improved visibility into allocations and valuations while maintaining auditable historical records.

**Technologies:** Java, React, SQL, Data Integration, Business Rules, Financial Calculations

---

### 5. Hand Gesture Recognition & Touchless Media Control

**Domain:** Computer Vision | Machine Learning | Human-Computer Interaction

**Situation:** Traditional media-player controls required physical interaction with a keyboard, mouse, or remote.

**Task:** Develop an application that recognizes hand gestures from depth-camera images and translates them into VLC Media Player commands.

**Action:**
- Used Microsoft Kinect and libfreenect to acquire depth frames.
- Applied depth thresholding and image segmentation to isolate hand gestures.
- Extracted image features using Histogram of Oriented Gradients (HOG).
- Trained a linear Support Vector Machine (SVM) classifier to recognize predefined gestures.
- Integrated real-time predictions with VLC controls for playback, navigation, and volume adjustment.

**Result:** Built an end-to-end touchless media-control application, demonstrating practical integration of computer vision, machine learning, sensor processing, and desktop software.

**Technologies:** Python, OpenCV, Microsoft Kinect, libfreenect, NumPy, Scikit-learn, HOG, SVM, VLC

**Source Code:** [Hand Gesture Recognition Using Depth Camera](https://github.com/ankita2210/Hand-Gesture-Reognition-using-Depth-Camera)
